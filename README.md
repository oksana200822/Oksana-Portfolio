# Portfolio Oksana Khoirunnida

Portfolio React dengan Vite. Konten diperbarui berdasarkan CV Oksana Khoirunnida.

## Menjalankan

```bash
npm install
npm run dev
```

## Build produksi

```bash
npm run build
npm run preview
```

Unggah isi folder `dist` ke hosting statis. Gunakan Node.js 22.12+ atau 24+.

Konten halaman berada di `src/main.jsx`, desain di `src/styles.css`, foto dan CV unduhan di `public/`. Jika CV diperbarui, ganti file di `public/` agar unduhan ikut diperbarui. File `script.js` dan `styles.css` di root adalah versi lama yang tidak lagi dimuat.
